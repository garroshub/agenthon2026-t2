V3-HS runtime-repair prompt contract

Facts require only fact_id, doc_id, exact quote, and claim. The runtime resolves publication date and source offsets.
Assumptions are optional and may be empty.
Non-abstain outputs require at least one fact and exactly two scenarios.
Each scenario has one or two factors and complete target-asset coverage.
Loading values are -1, 0, or 1; omitted declared factor IDs inside an existing asset map are interpreted as zero.
The runtime accepts one JSON object even if fenced or lightly wrapped in prose, but rejects multiple JSON objects.
Fabricated quotes/documents, unknown refs/assets/factors, non-enum loadings, equivalent scenario graphs, future leakage, and numerical pathologies remain fail-closed to exact V2.
Numerical graph design remains MIX_ALPHA=0.25 and SCENARIO_STRENGTH=0.50.
